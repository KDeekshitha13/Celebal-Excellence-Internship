# Week 5 Assignment — Data Cleaning and Transformation using Spark

## Overview

This assignment focuses on understanding big data processing concepts and performing data cleaning, transformation, filtering, and aggregation on structured data.

The main objective was to understand the advantages of modern distributed processing systems over traditional approaches and build a complete data processing pipeline.

## Dataset

For this assignment, I created and used my **own synthetic dataset** containing all the required fields specified in the assignment.

A single dataset was used throughout the assignment to perform all required operations, including duplicate removal, null handling, filtering, aggregation, schema modification, and pipeline creation.

## Implementation

The following operations were performed during the assignment:

* Loaded and explored the dataset
* Removed duplicate records
* Handled null and inconsistent values
* Applied filtering conditions
* Performed aggregation and grouping operations
* Modified schema by converting data types
* Built a complete data processing pipeline

## Key Insights

* In-memory computation significantly improves processing speed.
* Data cleaning improves data quality and analysis accuracy.
* Grouping operations may involve data redistribution during execution.
* Data pipelines help organize transformations efficiently.

## Conclusion

This assignment provided practical experience in handling structured data, cleaning inconsistent records, applying transformations, and building scalable data processing workflows.
