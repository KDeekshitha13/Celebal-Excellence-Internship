# Week 6 – Apache Spark Assignment

## Objective
The objective of this assignment is to understand Apache Spark architecture and perform efficient data processing using PySpark in Databricks. It covers schema handling, transformations, filtering, null value handling, file formats, and Spark performance optimization techniques.

## Tools & Technologies
- Apache Spark
- PySpark
- Databricks
- Python

## Tasks Performed
- Understood Spark Architecture, including the Driver, Cluster Manager, and Executors.
- Explored Lazy Evaluation and the Directed Acyclic Graph (DAG) execution model.
- Read data from CSV and Parquet files with proper schema handling.
- Applied filtering, column selection, renaming, type casting, and new column creation.
- Handled missing values and performed data transformations.
- Built an end-to-end data pipeline (Read → Transform → Filter → Write).
- Saved processed data in both CSV and Parquet formats.
- Learned Spark optimization concepts such as Shuffle, Predicate Pushdown, and best practices for processing large datasets.

## Key Concepts Covered
- Spark Architecture
- Lazy Evaluation & DAG
- Transformations & Actions
- Wide Transformations & Shuffle
- Predicate Pushdown
- CSV vs Parquet
- Schema Inference
- Null Handling
- Spark Performance Best Practices

## Conclusion
This assignment provided hands-on experience with Apache Spark using Databricks. It demonstrated how to build efficient data processing pipelines while understanding Spark's execution model and performance optimization techniques for large-scale data processing.
