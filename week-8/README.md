# Week 8 – E-Commerce Order Analytics System

## Overview
This project was completed as part of the **Celebal Technologies Internship – Week 8**. The objective is to build an end-to-end E-Commerce Order Analytics System using Python, SQL, and Databricks. The project covers data generation, data cleaning, SQL-based business analysis, report generation, and data validation.

## Technologies Used
- Python
- Pandas
- SQL
- Databricks
- Apache Spark

## Project Components
- **Data Generation:** Created realistic e-commerce datasets with intentional data quality issues.
- **Data Cleaning:** Cleaned and standardized data, handled missing values, validated emails, and checked referential integrity.
- **SQL Analysis:** Performed business analysis using joins, CTEs, subqueries, and window functions.
- **Report Generator:** Generated summary reports including total orders, revenue, unique customers, and top-selling products.
- **Edge Case Testing:** Validated scenarios such as invalid order IDs, invalid discounts, zero quantities, and future order dates.

## Outcome
This project demonstrates practical skills in data processing, SQL analytics, data validation, and building end-to-end data solutions using Databricks.
